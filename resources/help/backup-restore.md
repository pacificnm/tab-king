# Backup and restore

Choose **File → Backup / Restore**.

## Back up

**Back up now** writes one .zip file into your backup folder (change it in [Preferences](help:preferences)). It contains your database and every file in the library, plus a note of the Tab King version and when it was made. Keep copies somewhere safe, such as an external drive.

## Restore

1. Choose **Restore from backup…** and pick a backup .zip.
2. Tab King checks the file and shows what is inside. Backups from a newer Tab King than yours are refused.
3. Confirm. Your **whole library is replaced** by the backup's, and Tab King restarts.

If anything is wrong with the file, nothing is changed. Preferences (theme, folders, audio) are not part of a backup and are kept as they are.

> Restoring replaces everything currently in your library. Make a backup first if you might want it back.
