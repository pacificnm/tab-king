# Troubleshooting

## A song says a file is missing

The copy in the library folder was moved or deleted. Open the song, choose **Edit**, and pick the file again.

## No sound

- Check the output device in [Preferences](help:preferences) and your system volume.
- Make sure the track is not muted and its volume is up.
- If the audio source is set to MP3, check that the MP3 loaded; the player shows a message if it did not.

## The cursor drifts from the recording

Open **Sync audio…** and set the start offset, then add a sync point wherever the drift starts. See [MP3 audio and sync](help:mp3-sync).

## Restoring says the backup is from a newer version

Update Tab King (**Help → About → Check for updates**) and try again.
