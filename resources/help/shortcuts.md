# Keyboard shortcuts

These work in the player when you are not typing in a text box.

| Key     | Action               |
| ------- | -------------------- |
| `Space` | Play / pause         |
| `Home`  | Go back to the start |
| `[`     | Slower               |
| `]`     | Faster               |
| `L`     | Loop on / off        |
| `M`     | Metronome on / off   |
| `C`     | Count-in on / off    |

## Menus and lists

| Key         | Action                                  |
| ----------- | --------------------------------------- |
| `↑` `↓`     | Move through the library tree or a menu |
| `→` `←`     | Expand or collapse                      |
| `Enter`     | Play the focused song / activate        |
| `Shift+F10` | Open the right-click menu               |
| `Esc`       | Close the menu, flyout or dialog        |
